# 🚀 Web View
> An AI centered microservice that empowers users to create reports, graphs/charts, and basic calculators as an interfaceable web application.

---

## 🌟 Features
* **Report Generation** – Seamlessly generate report tables, graphs, and charts with your AI agent.
* **Calculator Creation** – Effortlessly create calculators for important metrics and quick calculations.
* **Responsive Design** – Live edit your view directly with your AI agent for automated workflow optimization!
* **Authentication & Security** – Ensure all your proprietary data as safe and carefully managed.

## 🛠️ Tech Stack
* **Frontend:** Gemini / Python / HTML / CSS
* **Backend:** Python FastAPI
* **Database:** PostgreSQL
* **Deployment:** Docker
